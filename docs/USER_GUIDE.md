# 使用说明

## 开始使用

运行 `TaskHarbor.exe`，点击屏幕边缘的把手展开。托盘也提供打开工作台、小面板、暂停提醒与退出入口。顶部“固定”可阻止自动收起；“小面板／工作台”在同一窗口切换布局。

默认鼠标移开 1 秒收起，设置中可选择 1、3、5、10 秒或仅手动。输入未保存任务、编辑、确认和 AI 整理期间保持展开。按住标题栏移动面板，按住把手可拖动贴边位置。

## 新建与安排

输入内容并按 Enter 即可添加。底部选择本日、本周、本月和所属象限；选择会记住。需要期限时展开“截止时间 · 可选”，填写日期和时刻。没有日期的任务不会因为周期结束自动逾期。

- 今天：安排在今天的日计划；默认额外包含逾期任务，可以在设置关闭。
- 本周：本周日计划与周计划，不自动包含整月计划。
- 本月：与本月重叠的日、周、月计划。
- 全部：全部未删除的任务。

周期均按本地日历计算，一周从周一开始。筛选与新建计划分别控制；新任务不符合当前筛选时，提示中的“查看”可打开全部，不悄悄更换当前视图。

## 编辑、子任务与批量操作

点击任务标题或“编辑”打开侧边编辑。计划日期决定所选日、周、月的归属；修改计划不会覆盖已有截止时间。保存后才生效，关闭未保存编辑会再次确认。

每项支持最多 50 个子任务。子任务勾选在“保存修改”后写入；不会自动将主任务标记完成。

“批量”进入选择模式，可批量完成、安排今天或移入回收站。拖动任务到其他象限也能归类；不便拖动时可直接在编辑页选择象限。

## 恢复与保存

完成、编辑和移入回收站等操作可撤销上一步。提示可关闭；焦点不在输入框时，Ctrl+Z 也可撤销。

设置中的“回收站”可以恢复已删除任务。不会自动清空；永久清空需要明确确认且不可撤销。

宿主写入成功后才显示“已保存到本机”。保存失败会还原任务状态、保留录入内容，并提供重试。任务文件损坏时阻止继续写入，先通过备份或原始文件恢复，避免以空数据覆盖。

## 重复任务与提醒

重复规则为“完成后生成下一日／周／月”。下一次会继承象限、内容、子任务与提醒偏好，子任务状态重置。跨月日期使用原始月日锚点，例如 1 月 31 日 → 2 月末 → 3 月 31 日。晚完成只生成一个当前／后续周期实例，不批量补建错过的任务。

撤销完成会连同刚生成的实例一起撤销。单独取消旧任务的完成不会自动删除已生成的后续实例，也不会在再次完成时重复生成。

在编辑页勾选任务提醒，并在设置中允许提醒。需要程序运行：日期和时刻均填写则按该时刻提醒；只填日期则当天 09:00 提醒。系统侧约 10 秒检查一次，最多补查过去 24 小时。默认 22:00–08:00 静默，结束后补查范围内的待提醒项。通知不会显示任务标题；点击打开任务。托盘可以暂停 1 小时，任务可以延后 15 分钟。

退出程序后不会提醒，Windows 通知策略或免打扰可能抑制显示。本版本不安装系统计划任务，也不承诺关闭应用后的提醒。

## AI、数据与迁移

手工任务不需要配置 AI。AI 整理只在主动点击生成时发送文字及所选图片到设置中的服务。最多 3 张图片，生成后可改标题、象限、计划及截止时间，再选择加入。远程服务需要 Key，本地回环服务可以不填。

默认目录 `%APPDATA%\TaskHarbor`。首次正常启动复制旧版 DeskTodo 默认数据和配置，保留原文件；旧自定义任务路径继续沿用。已有截止日期保留，不自动清空或改成周日。第一次写入前生成 `.before-taskharbor-v3.bak`。设置可导出／导入；导入前自动生成 `backups/tasks-before-import-*.json`。

API Key 仅当前 Windows 用户可解密，不随任务导出。备份 JSON 是明文，分享前自行检查内容。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 全局唤出录入 | Ctrl+Shift+T（注册成功时） |
| 搜索 | Ctrl+F |
| 聚焦录入 | Ctrl+N |
| 保存编辑 | Ctrl+Enter |
| 撤销任务操作 | Ctrl+Z（输入框外） |
| 返回、关闭编辑、取消批量、收起 | Esc，按当前所在层处理 |
